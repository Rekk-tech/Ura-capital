# FEAT-038 Spec: Simulation Learner UI

## UI Scope

- Session management.
- Asset list.
- MARKET order ticket.
- Portfolio summary.
- Positions.
- Orders.
- Trades.
- Current PnL/equity.

Historical valuation chart is deferred.

## Mandatory Copy

Every Simulation page must clearly state:

- SIMULATION ONLY
- NO REAL MONEY
- NO BROKERAGE EXECUTION

Use product-neutral wording. Avoid gambling-like framing.

## Authority

Frontend submits intent only. Server DTOs own all authoritative values.
